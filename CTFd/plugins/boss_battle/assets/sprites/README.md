# Boss Battle Sprite Sheets

Place sprite sheet PNG files in this directory.

## Expected Files

| Filename | Dimensions | Frames | Description |
|---|---|---|---|
| `phase1_idle.png` | 2048×256 | 8 frames | Starscourged General idle loop |
| `phase1_attack.png` | 2048×256 | 8 frames | Wide Slash attack |
| `phase2_idle.png` | 2560×256 | 10 frames | Gravity Lord idle loop |
| `phase2_attack.png` | 2048×256 | 8 frames | Spinning Slash / Gravity Pull |
| `phase3_idle.png` | 2560×256 | 10 frames | Promised Consort idle loop |
| `phase3_attack.png` | 2048×256 | 8 frames | Divine Slash |

## Format Requirements

- **Frame size:** 256×256 pixels each
- **Layout:** Horizontal strip (frames side-by-side left to right)
- **Background:** Transparent (PNG)
- **Target FPS:** 10–12 FPS
- **Style:** Pixel art, rendered at native resolution
